    Settings

    AI Model

    Default: gemma4:e2b (~4.6 GB RAM)  |  Lighter, for 8 GB machines: qwen2.5:3b-instruct (~2.1 GB)
    Install: ollama.com → then run: ollama pull gemma4:e2b

    Or type any model ID from openrouter.ai/models:

    Get a free API key at openrouter.ai — free models cost $0.

    API Keys

    Google OAuth (Gmail)

    Required for Email Intelligence. Get credentials from console.cloud.google.com → APIs & Services → Credentials → Create OAuth 2.0 Client ID (Desktop app). Add http://localhost:3000/oauth2callback as an authorized redirect URI.

    OpenRouter API Key

    Paste your OpenRouter key to use free open-source models (Gemma, Qwen, LLaMA, Mistral, DeepSeek…). Get one free at openrouter.ai.

    Database

    Export Database

    Save a backup of all your data for transfer to another machine.

    Import Database

    Restore data from a backup file.

    Student Data Key

    Student names and IDs are encrypted with a key stored in Windows Credential Manager. Save a recovery file somewhere safe (USB drive, cloud folder) — without it, a reinstall or new Windows profile cannot read your student data.

    Save Recovery File

    Protected by a passphrase you choose. Keep the passphrase separate from the file.

    Restore From Recovery File

    Use when this computer has lost the key.

    Portable Mode

    Enable this before moving FacultyMind to a USB drive or another PC without Windows Credential Manager.
